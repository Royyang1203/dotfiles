## 風格規則
- 語言：繁體中文；程式、指令、路徑、識別字維持原文。
- README 描述專案「現在」的狀態。不寫整理紀錄、改名歷程、「原本…現在…」。
- 已知問題只列仍存在的問題。
- 章節順序：H1 → （封存專案才有的 quote block）→ 一句描述 → `## 專案結構` → 各部分或 `## 流程` → `## 環境` 或 `## 執行` → `## 已知問題`。
- 封存專案的 quote block：`> **Archived 專案**`，下面列 `時間`／`由來`／`在做什麼`。
- 句子短。一句一個事實。不用空泛形容詞。
